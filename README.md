## バランス調整用のツール

数値はボットに遊ばせて決めている。Node.jsで動く。

```bash
# コア・ディガー：各層に着くまでの時間
cd core-digger/tools && node sim.js

# けものの星のカードバトル（CPU同士で戦わせる）
cd pack-opener
node tools/bal.js 3000      # 先攻の勝率・試合の長さ・パック数ごとの勝率
node tools/card.js 500      # カード1種ごとの強さ（コモン2枚と入れかえたときの勝率）
node tools/foes.js 300      # CPUの相手ごとの勝ちやすさ（パックを開けた数ごと）
node tools/sets.js 2000     # 第一弾と第二弾のデッキの強さくらべ
SET=2 node tools/card.js 500   # 第二弾のカード1種ごとの強さ
node tools/evo.js 1000      # 第三弾（進化デッキ）と第一弾・第二弾の強さくらべ
node tools/vs.js 4 1 1000   # 弾どうしの強さくらべ（第四弾 vs 第一弾）
cd ..

# ほったらかし釣り堀：池ごとにかかる時間（引数はタップする割合と回数）
cd idle-fishing && node tools/sim.js 0 6

# 物件王インクリメンタル：章ごとの到達時間と総売上の伸び
cd bukken-ou/incremental/tools && node curve.js core.js auto
```

## うぱるぱスピリッツ（upa/）

ぜんぶウーパールーパーの3D野球（パワプロ風）。Three.js（`upa/vendor/` に同梱、MITライセンス）で球場も選手もその場で作っています。

- 試合：CPU戦（3・6・9回、強さ3段階、デーゲーム／ナイター）と、部屋番号のオンライン対戦
- 打撃はミート打ちと強振（Shift／強振ボタン）。実況テロップと効果音つき
- 能力はパワプロ式：弾道・ミート・パワー・走力・肩力・守備・捕球、投手は球速・コントロール・スタミナ・変化球。特殊能力（チャンス◎、ノビ○、レーザービームなど）が打球や投球の計算に効く。投手は投げるほど疲れて、ヘトヘトになるとリリーフに交代。エラーもある
- サクセス：ウパ高校で3年間（30週）。練習・仲間・イベント・夏の大会（自分の打席や登板は試合のルールで計算）で経験点をため、能力アップして選手を作る
- チーム：全チームの能力表。サクセスの選手を入れた「マイチーム」を作れて、CPU戦やオンラインで使える（オンラインでは相手の画面にもチームのデータを送る）
- `engine.js` がルールと物理（画面なし）、`success.js` がサクセス。`node upa/tools/sim.mjs 300` でCPU同士の打率・点数・継投・エラーを確認
- 画像：`images/cards/<チーム>_<打順>.webp`（選手カード36枚）と `images/icon.webp`。プロンプトは `node upa/tools/prompts.mjs` → `tools/prompts.txt`

## 奈落の迷宮（naraku/）

ダークファンタジーのターン制ローグライク（不思議のダンジョン風）＋タルコフ風の「持ちこみ・持ち帰り」。3D（Three.js）でスマホも遊べる。

- 出撃準備：倉庫から持っていく物をえらぶ（18個まで）。支給セット（錆びた剣・木の盾・黒パン・回復薬）はいつでも無料（売っても1G）
- 帰還：帰還の魔法陣（地下2階から、3の倍数の階は必ず・ほかは30%）か帰還の巻物で地上へ。拾った物は鑑定されて倉庫へ。力つきたら持っていった物も拾った物もぜんぶなくなる

- スマホ：行きたい所をタップで自動移動、🔍自動探索、早送り。十字キーはメニューで出せる
- 今日の奈落：日付で決まる同じマップ。1日1回、帰還で +200G

## 出社できない（shusha/）

足がいうことをきかない会社員を、会社まで歩かせるクソゲー（QWOP風）。Q/W でふともも、O/P ですね（スマホは画面下の4ボタン）。頭か体が地面についたら転んでやりなおし。

- 全11ステージ：家の前・歩道の段差・だらだら坂・凍った道・向かい風（突風）・工事中（バー）・月面出張（重力1/6）・動く歩道（逆走）・満員の改札（押す）・会社の階段・社長室の前（バナナ）
- ステージごとのベストタイムと転んだ回数を記録。同じステージで5回転ぶとコツが出る
- 全ステージクリアで「エンドレス出社」：11ステージの仕掛けがランダムに続く（毎回ちがうコース、進むほど間がつまる）。距離で「新入社員→主任→係長→課長→部長→…→社長→会長→伝説の会社員」と出世。ランキングはエンドレスの最高距離（`shushae`）
- `physics.js` が planck.js（Box2D、`vendor/`）でのラグドールとステージ。node から動かせるので、リズムで押すボットで全ステージがクリアできることを確認ずみ

- 画質は ☰メニューで「ひくい・ふつう・たかい」（スマホは最初「ふつう」）。`?gq=0〜2` でも指定できる。`vendor/` は Three.js r160 のポストプロセス

- 歩くとブラシでホコリがとれる → ゲージが満タンになったら📦パック → 基地の回収口（オレンジの輪）か集積所（青い輪）に入ると売れる
- 4×4の16地区（1地区64m）。外側ほど上質なホコリで高く売れる（$5・$8・$12/kg）。98%きれいにすると地区クリアボーナス
- ショップ：道具6種（歯ブラシ→月面モップ）、強化（圧縮タンク・カプセルベルト・ワイドヘッド・ムーンブーツ・オートパッカー・ホコリ鑑定）、集積所（最大8）、ガレージと清掃車4種、おそうじロボ3種（最大12台。留守中も最大1時間はたらく）
- ホコリの下に落とし物が14こ。掃除すると出てくる
- ホログラムマップ（M）で地区ごとの清掃率。ランキングは月面清掃率
- `world.js` が地形・クレーター・ホコリの地図（0.25mマス×1024×1024）とセーブの圧縮。`game.js` が本体
- テスト用：`?bot=1&fast=8` で自動操作・早送り

## GAMES アカウント

トップ右上で「プレイヤー名」を決められます。集めるのは名前だけ（メール・本名・パスワードなし）。claude.ai で開いたときは共有の名簿で同じ名前を使えないようにし、それ以外ではその端末だけに保存します。オンライン対戦の名前に自動で入ります（`account.js`）。

## ウパラン（runner/）

ウーパールーパーが自動で走りつづける3Dのエンドレスラン。3レーンで、スワイプ（PCは矢印キー・WASD）でレーン移動・ジャンプ・スライディング。

- 障害物：低い柵（ジャンプ）・頭の高さのバー（スライディング）・箱と水槽トラック（レーンを変える。横からぶつかると押しもどされる）
- しずくを集めて「きがえ」（体の色8種類）。アイテムはマグネット・あわバリア・スコア2倍・スーパージャンプ
- 走るほど速くなり、800mごとに朝→昼→夕方→夜→ネオンと景色が変わる。ハイスコアと記録（上位10回）はこの端末に保存
- `gen.js` がコースの自動生成。どの列にも必ず抜けられる道を残す。`node runner/check.mjs` で確認（30万列で通れない列0）
- テスト用：`?bot=1&fast=8` で自動操作・早送り
- Three.js は `upa/vendor/` のものを使う
