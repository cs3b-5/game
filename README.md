# ゲーム置き場

ブラウザで遊べるゲームと、その試作の記録。どれもHTMLファイル1つで動く（インストール不要）。

| フォルダ | 中身 |
| --- | --- |
| `core-digger/` | **コア・ディガー**：一人称で洞窟の壁を掘り、つるはしとドローンを強化して地球の中心を目指すインクリメンタル（Three.js） |
| `ad-closer/` | **閉じろ！広告地獄**：湧いてくる広告を×で閉じまくる。画面が埋まったら終わり、コインで強化して周回（PC向け） |
| `bukken-ou/incremental/` | 物件王・インクリメンタル版（最新）。デスク10台＝物件10段階、社員で自動化、会社売却で周回 |
| `bukken-ou/office-v2/` | 物件王・ドット絵オフィス1画面版（経営シム）。売主・応募者をタップ、社員がチームで作業 |
| `bukken-ou/office-v1/` | 物件王・カード＋オフィス版（経営シム）。家具の配置で動線を作る |
| `bukken-ou/3d-mockups/` | 3Dの街のイメージ図（`images/`）と、それを描いたThree.jsのページ（`scene.html` `era.html`） |
| `orbit-hop/` | オービットホップ：ワンボタンの宇宙ジャンプゲーム |

## 遊び方

- フォルダの `index.html` をブラウザで開くだけ（Chromeなど）
- 一番上の `index.html` はゲームの一覧ページ
- 3Dのもの（コア・ディガー、イメージ図）は Three.js を jsDelivr から読み込むので、ネットにつながっている必要がある

### コア・ディガーの操作（PC）

| 操作 | キー |
| --- | --- |
| 歩く | WASD |
| 見回す | マウス（最初に画面をクリック） |
| 掘る | 左クリック長押し（スペースでも可） |
| ショップ | E |

## バランス調整用のツール

数値はボットに遊ばせて決めている。Node.jsで動く。

```bash
# コア・ディガー：各層に着くまでの時間
cd core-digger/tools && node sim.js

# 物件王インクリメンタル：章ごとの到達時間と総売上の伸び
cd bukken-ou/incremental/tools && node curve.js core.js auto
```

## セーブ

ブラウザの localStorage に自動保存。各ゲームの中の「セーブデータ」から書き出し・読み込みもできる。
